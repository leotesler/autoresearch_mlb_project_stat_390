What's in this repo?

Quick access:

Experiment log can be found at `autoresearch/results.csv`.

Final report can be found at `reports/STAT_390_Capstone_Project_Final_Report.pdf`.

Subdirectories:

`autoresearch/`: Files used to train the AI agent, and process loop results.

`baseline_model/`: Files used to create and train the baseline lasso model.

`clean_data/`: Cleaned MLB and MiLB datasets used for model training.

`data_processing/`: Scripts used to pull and clean MLB and MiLB data.

`images/`: Plots and tables used in reports and assignments.

`reports/`: Agent-generated loop summaries, and assignment reports.
